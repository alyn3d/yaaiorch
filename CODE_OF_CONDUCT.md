# Code of Conduct

YAAIORCH follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, assume good intent, give and accept constructive feedback
gracefully, and focus on what is best for the project and its community. Harassment, personal attacks,
discriminatory language and publishing others' private information are not acceptable, in project
spaces or when representing the project elsewhere.

## Reporting

Report unacceptable behaviour to the maintainer through a
[private GitHub security advisory](https://github.com/alyn3d/yaaiorch/security/advisories/new)
(use it for conduct reports too) or by contacting [@alyn3d](https://github.com/alyn3d) on GitHub.
Reports are handled confidentially. The maintainer may remove, edit or reject contributions, and
warn, suspend or ban participants, following the enforcement guidelines of the Contributor Covenant.
